# Mock 服务说明

使用 `axios-mock-adapter` + `mockjs` 拦截请求返回模拟数据，无需启动后端即可开发前端。

## 使用方式

- `src/main.js` 中已默认导入 `import './mock'`
- 如需连接真实后端，注释掉该行即可
- 模拟数据延迟 400ms

## 已覆盖接口

- 认证：登录/登出/注册
- 图书：CRUD、搜索、库存预警、导入导出
- 分类：CRUD、树形列表
- 用户/管理员：CRUD
- 借阅：借阅/归还/取消/逾期
- 电子书：列表/详情/章节/上传
- 排行：借阅排行/阅读排行
- 收藏：切换/列表/排行
- 审计日志
